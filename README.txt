# Money Mind Website

A responsive one-page website for Money Mind, a youth-led organization focused on practical financial knowledge and confidence.

## Files
- `index.html` — main website content
- `styles.css` — design and responsive layout
- `script.js` — mobile menu and dynamic copyright year
- `assets/money-mind-logo.png` — uploaded Money Mind logo

## Updating events
Open `index.html` and edit the two cards inside the `#events` section. You can duplicate an `.event-card` to add more events or workshops.

## Updating departments
Edit the department cards inside the `#departments` section.
